Habr Career Vacancy ETL

Проект предназначен для регулярного сбора актуальных вакансий с сайта Habr Career (career.habr.com) по заданным ключевым словам.

ETL-пайплайн на Apache Airflow: регулярный сбор вакансий по ключевым словам, парсинг, загрузка в PostgreSQL и уведомления в Telegram об успешной загрузке и ошибках.

// Стек

Python 3.12 Apache Airflow 2.10 httpx (async) PostgreSQL psycopg2 Telegram Bot API Docker Compose Poetry

// Структура проекта

dags/habr_career_etl.py     — DAG Airflow
src/
 ├── api/                    — парсер (JSON API)
 ├── database/               — работа с БД
 ├── models/                 — Vacancy, Employer
 └── notifications/          — Telegram-уведомления
run_etl.py                  — локальный запуск

// Основные сущности

КлассНазначение
Vacancyid, название, url, зарплата, регион, компания
Employerid, название, url
HabrCareerVacanciesSourceИсточник данных (JSON API)
HabrCareerDBCreatorСоздание и подготовка таблиц
HabrCareerDBWriterЗапись компаний и вакансий

// Функционал

  • Асинхронный сбор через официальный JSON API Habr Career
  • Парсинг зарплат (если только «от» — «до» = «от»)
  • Нормализованная структура: компании + вакансии
  • Автоматическая очистка таблиц перед каждой загрузкой
  • Уведомления в Telegram об успешном завершении и ошибках
  • Запуск по расписанию через Apache Airflow
  • Возможность запуска вручную (локально и в Docker)
  • Поддержка параметров DAG: ключевые слова и количество страниц

// Архитектурные решения

  • Разделение оветственности: Extract → Load
  • Асинхронный сбор данных с asyncio.Semaphore (контроль параллельности)
  • Использование JSON API вместо HTML-парсинга (более стабильный подход)
  • Возможность парсинга данных из HTML-страницы (для отладки и резервного варианта)
  • Отдельные транзакции: подготовка таблиц и запись данных
  • Логирование, совместимое с Airflow UI
  • Конфигурация через .env, контейнеризация всего стека
