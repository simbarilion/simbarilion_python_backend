GitHub Analytics

Система для поиска популярных GitHub-репозиториев с аналитикой и Google Sheets Dashboard

FastAPI-сервис для поиска репозиториев через GitHub Search API с агрегацией метрик, экспортом JSON/CSV и интеграцией с Google Sheets для интерактивного дашборда

// Стек

FastAPI httpx + asyncio Pydantic Docker Google Apps Script Cloudflare Tunnel pre-commit

// Структура

app/
 ├── main.py
 ├── github_client.py    — API-запросы к GitHub
 ├── services.py         — обработка и агрегация
 ├── schemas.py          — Pydantic-схемы
 ├── storage.py          — сохранение JSON/CSV
 └── core/               — config, logging
google_sheets/Code.gs    — Apps Script интеграция

// FastAPI backend

  • Поиск репозиториев через GitHub Search API с фильтрами по языку и min_stars
  • Пагинация: до 100 результатов на странице, максимум 1000 результатов всего
  • Асинхронные запросы: httpx + asyncio.gather
  • Агрегация данных: total stars, average stars, top repository
  • Вывод данных по каждому репозиторию: название, автор, количество звезд (популярность проекта в мире), количество форков (сколько раз проект был скопирован другими разработчиками), URL репозитория (для быстрого доступа к проекту на GitHub)
  • Экспорт в JSON и CSV

// API

GET /search?query=fastapi&language=python&limit=200&min_stars=10

{
  "query": "fastapi",
  "repos_count": 200,
  "total_stars": 120000,
  "average_stars": 600,
  "top_repo": "tiangolo/fastapi",
  "repos": [...]
}

// Google Sheets Dashboard

  • Проект интегрирован с Google Sheets через Google Apps Script
  • Меню GitHub Loader → Load repos (OPEN DASHBOARD / QUICK LOAD)
  • 2 режима загрузки данных: OPEN DASHBOARD - с выбором параметров поиска, QUICK LOAD - быстрая загрузка с параметрами по умолчанию
  • Apps Script выполняет HTTP-запрос к FastAPI backend, записывает данные в таблицу
  • Лист DATA — данные репозиториев, обработка ошибок API
  • Лист DASHBOARD — метрики, Top 10 Stars, Top 10 Forks (автодиаграммы)

// Доступ к backend

Docker для локального запуска. Cloudflare Tunnel для публичного HTTPS без деплоя сервера — Apps Script обращается к backend через туннель.

// Качество кода

Структурированное логирование, конфигурация через env, OpenAPI/Swagger UI, pre-commit hooks, контейнеризация.
