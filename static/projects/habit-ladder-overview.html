HabitLadder

Backend SPA для формирования полезных привычек

Backend-часть приложения на основе идей «Атомных привычек» Джеймса Клира: CRUD привычек, email-активация, Telegram-напоминания по таймзоне пользователя, строгая система прав.

// Стек

Django 5.2 DRF PostgreSQL Celery + Redis Telegram Bot API ZoneInfo CORS pytest (~90%) Docker / CI/CD

// Модели

Habit — place, habit_time, action, is_pleasant, related_habit, periodicity (1–7 дней), reward, duration (≤120 сек), is_public.

CustomUser — email-логин, Telegram chat_id, timezone, статус активации.

// Валидаторы

  • Нельзя одновременно указать reward и related_habit
  • Только приятные привычки могут быть связанной привычкой
  • duration ≤ 120 секунд, periodicity 1–7 дней

// Права доступа

  • Пользователь — CRUD только своих привычек
  • Публичные привычки — read-only для всех авторизованных
  • Суперпользователь — видит все привычки

// API и документация

REST API с пагинацией и CORS для фронтенда. Swagger / Redoc: /swagger/, /redoc/.

// Деплой

Django + Gunicorn + Nginx + PostgreSQL + Redis + Celery Beat. CI/CD через GitHub Actions: lint → tests → Docker build → deploy на VPS.
