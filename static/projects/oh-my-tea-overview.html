Oh! my tea — YML Feed

Автоматизация генерации товарного YML-фида для магазина чая

Конвейер: каталог товаров → валидация по бизнес-правилам → отчёт (included/excluded) → YML XML для Яндекс.Маркета и Яндекс.Директа. Backend на Python + интерактивное демо на GitHub Pages.

// Стек

Python ≥3.12 ElementTree Decimal pytest (17 тестов) Poetry JavaScript (демо)

// Архитектура

Каталог (товары + категории)
        ↓
   Валидация по бизнес-правилам
        ↓
   Отчёт (included / excluded + причины)
        ↓
   Сборка YML (валидный XML)
        ↓
   Публикация в рекламные площадки
    
Backend (Python)                    Демо (GitHub Pages)
validators → report                 index.html + app.js
builders → YML XML        ──────►   data.json
demo_export → JSON                  GitHub Pages

// Модули Python

КомпонентНазначение
validatorsБизнес-правила, validate_product() с причинами отказа
buildersФильтрация и сборка YML через ElementTree
reportОтчёт: included / excluded
demo_exportЭкспорт JSON для интерактивного демо

// Правила валидации

Товар попадает в фид, если все условия выполнены:

ПравилоУсловие
Активностьis_active = true
Категориясуществует и активна
Названиене пустое после trim
Ценабольше нуля
ИзображениеURL начинается с http:// или https://

При сборке XML: available по остатку, oldprice только если > текущей, цены в формате 490.00, дата фида YYYY-MM-DD HH:MM.

// Результат на демо-данных

12 товаров → 6 в фиде, 6 отсеяно (6 типов причин: отключён, цена 0, нет фото, категория недоступна, нет названия, неверный URL).

// Production-сценарий

Интеграция в Django: endpoint /feeds/yml.xml, queryset из БД, регенерация по cron. Демо-репозиторий — визуализация логики для заказчика без доступа к исходному backend-коду.

// Тестирование

17 автотестов: YML-фид, отчёт, экспорт, edge cases (спецсимволы, oldprice, available).
